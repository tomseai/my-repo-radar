# Evidence Policy

Imported GitHub metadata records when it was fetched. Agent-authored claims
must cite a primary source and the date on which it was checked.

Preferred sources, in order, are repository files, official documentation,
release notes, and maintainer announcements. GitHub topics and repository names
are discovery hints, not proof of a capability.

Every evidence item identifies the claim it supports, source type, source URL,
verification date, and confidence. If primary sources conflict or do not answer
the question, the record must say so and request review rather than infer an
answer.
